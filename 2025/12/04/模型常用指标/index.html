模型常用评估指标

发表于2025-12-04|更新于2026-04-21|机器学习模型评估

一、分类任务指标（预测类别标签，基于 TP/TN/FP/FN 计算）

真实正类 真实负类
预测正类 TP（True Positive/真阳性） FP（False Positive/假阳性）
预测负类 FN（False Negative/假阴性） TN（True Negative/真阴性）

1. 准确率（Accuracy）

  • 核心：预测正确的样本占总样本比例

  • 公式：$Accuracy = \frac{TP + TN}{总样本数}$（TP = 真阳性，TN = 真阴性，FP = 假阳性，FN = 假阴性）

  • 细节说明：仅反映 “整体正确率”，未区分正负类表现

  • 适用案例：类别均衡场景（如二分类正负样本各 50%，如 “判断邮件是否为工作邮件”）

  • 缺点：不平衡数据失效（如 99% 负样本，模型全预测负类也得 99% 准确率，但无实际价值）

2. 召回率（Recall / 查全率）

  • 核心：实际正类中被正确预测的比例（重点防 “漏判正类”）

  • 公式：$Recall = \frac{TP}{TP + FN}$（FN = 正类误判为负类，即 “漏判”）

  • 别名：灵敏度（Sensitivity）、真阳性率（TPR）

  • 细节说明：召回率高 =“正类几乎不会被漏掉”

  • 适用案例：漏判代价高场景（疾病诊断：漏判癌症患者会延误治疗；欺诈检测：漏判欺诈交易导致损失）

3. 精确率（Precision / 查准率）

  • 核心：预测为正类的样本中，实际为正类的比例（重点防 “误判正类”）

  • 公式：$Precision = \frac{TP}{TP + FP}$（FP = 负类误判为正类，即 “误判”）

  • 别名：阳性预测值（PPV）

  • 细节说明：精确率高 =“预测为正类的结果几乎都是对的”

  • 适用案例：误判代价高场景（垃圾邮件检测：误判正常邮件为垃圾，会导致用户错过重要信息；电商虚假评论识别：误判真实好评为虚假，影响商家信誉）

4. F1 分数

  • 核心：精确率与召回率的调和平均，平衡 “防漏” 与 “防误”

  • 公式：$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$

  • 细节说明：当精确率和召回率冲突时（如提高召回率会降低精确率），F1 是综合衡量标准；若需侧重某一方，可使用 Fβ 分数（β>1 侧重召回率，β<1 侧重精确率）

  • 适用案例：需兼顾误判 / 漏判场景（搜索排序：既不能漏搜相关结果，也不能推太多不相关内容；文本分类：如 “新闻分类为体育 / 财经”，既不能漏分体育新闻，也不能错把财经归为体育）

5. 混淆矩阵

  • 核心：以矩阵形式展示 “预测结果 - 真实标签” 的对应关系，是所有分类指标的计算基础

  • 二分类矩阵结构：

真实正类 真实负类
预测正类 TP（对） FP（错）
预测负类 FN（错） TN（对）

  • 细节说明：多分类时矩阵维度为 “类别数 × 类别数”（如 3 分类为 3×3 矩阵），可直观看到 “哪类样本易被误判为哪类”

  • 适用案例：定位模型误差类型（如手写数字识别，发现 “8” 常被误判为 “3”，可针对性优化模型）

6. AUC-ROC

  • 核心：ROC 曲线下的面积，衡量模型 “区分正负类” 的能力（与分类阈值无关）

  • ROC 曲线定义：横轴 = FPR（假阳性率 =$\frac{FP}{FP+TN}$，即负类被误判的比例），纵轴 = TPR（召回率 =$\frac{TP}{TP+FN}$）

  • 公式 / 取值：面积范围 0~1，0.5 = 随机猜测，越接近 1 性能越好

  • 细节说明：对类别分布不敏感（如正类占 10% 或 50%，AUC-ROC 变化小），适合一般不平衡数据

  • 适用案例：二分类模型评估（如信用评分：区分 “守信用户” 和 “失信用户”，无需提前设定 “信用合格阈值”）

7. AUC-PR

  • 核心：PR 曲线（横轴 = 召回率，纵轴 = 精确率）下的面积，比 AUC-ROC 更聚焦 “正类性能”

  • 细节说明：AUC-ROC 易受大量负类影响（如正类仅 1%，负类 99%，ROC 曲线可能仍接近 1，但 PR 曲线更能反映正类预测质量）

  • 适用案例：极不平衡数据（如罕见病诊断：正类占比 0.5%，需重点关注正类的 “查准” 与 “查全”）

8. 宏平均（Macro-average）/ 微平均（Micro-average）

  • 核心：多分类任务中综合所有类别的指标（解决 “类别样本数不平衡” 问题）

  • 计算逻辑：

    • 宏平均：先计算每个类的精确率 / 召回率，再取算术平均（平等对待每类，无论样本数多少）

    • 微平均：先汇总所有类的 TP、TN、FP、FN，再计算精确率 / 召回率（受样本数多的类影响大）

  • 细节说明：宏平均适合关注 “小众类”（如多分类中 “冷门标签”），微平均适合关注 “整体正确率”

  • 适用案例：多分类文本分类（如新闻分类为 “体育 / 财经 / 娱乐 / 科技”，若 “科技” 类样本少，用宏平均评估更公平）

二、文本生成任务指标（评估生成文本与参考文本的一致性）

1. Rouge 系列（1/2/L）

  • 核心：基于 “n-gram 重叠” 或 “最长公共子序列” 衡量文本相似度

  • 各类型公式（简化）：

    • Rouge-1：$=\frac{生成与参考共有的1-gram数}{参考文本的1-gram总数}$（1-gram = 单个词）

    • Rouge-2：$=\frac{生成与参考共有的2-gram数}{参考文本的2-gram总数}$（2-gram = 连续两个词）

    • Rouge-L：$=\frac{最长公共子序列长度}{参考文本长度}$（最长公共子序列 = 不要求连续但顺序一致的词序列）

  • 细节说明：

    • Rouge-1：衡量词汇级一致性（如 “猫吃饭” 和 “猫吃粮”，Rouge-1=2/3）

    • Rouge-2：衡量短语级一致性（避免 “词对但语义错”，如 “猫吃饭” 和 “饭吃猫”，Rouge-2=0）

    • Rouge-L：衡量语义级一致性（不依赖词序连续，如 “猫在桌上吃饭” 和 “吃饭的猫在桌上”，Rouge-L 高）

  • 适用案例：文本摘要（学术论文摘要常用 Rouge-1+2+L 组合评估）、机器翻译

2. BLEU（双语评估替换）

  • 核心：基于 n-gram 精确率 + 长度惩罚，避免生成 “过短文本” 投机取巧

  • 公式（简化）：$BLEU = BP \times exp(\sum_{n=1}^4 w_n \log p_n)$（n 通常取 1-4，w_n = 权重；BP = 长度惩罚，生成文本短于参考则 BP<1）

  • 细节说明：n-gram 精确率 =$p_n=\frac{生成与参考共有的n-gram数}{生成文本的n-gram总数}$，长度惩罚防止模型生成 “短而准” 的文本（如仅生成 “好的” 应对所有输入）

  • 适用案例：机器翻译（如英译中评估）、短句生成

  • 缺点：仅看词级重叠，不理解语义（如 “他打了球” 和 “球被他打了”，BLEU 高；但 “他喜欢球” 和 “他讨厌球”，若词重叠多，BLEU 也可能高）

3. METEOR

  • 核心：改进 BLEU，支持 “同义词 / 词形变化匹配”，更贴近人类判断

  • 细节说明：通过词库匹配同义词（如 “run” 和 “running”“奔跑” 视为匹配），同时计算精确率和召回率的调和平均，平衡 “查准” 与 “查全”

  • 优势：解决 BLEU “不辨语义” 的问题（如 “汽车” 和 “车辆” 可匹配）

  • 适用案例：文本摘要、机器翻译（尤其是需要语义一致性的场景）

4. BERTScore

  • 核心：用预训练语言模型（如 BERT）计算 “生成词” 与 “参考词” 的嵌入相似度，而非单纯词重叠

  • 细节说明：将生成文本和参考文本的每个词转化为 BERT 向量，计算余弦相似度，取平均值作为分数

  • 优势：捕捉语义一致性（如 “医生治疗病人” 和 “医师救治患者”，语义相近则分数高）

  • 适用案例：对话生成（如客服机器人回复质量评估）、创意写作（需语义连贯）

5. CIDEr

  • 核心：基于 n-gram 的 TF-IDF 加权，适合 “多参考文本” 场景（一张图 / 一个任务有多个正确答案）

  • 细节说明：对每个 n-gram 计算 TF-IDF（词频 - 逆文档频率），权重越高表示该 n-gram 越能区分 “正确参考” 与 “错误参考”，再计算生成文本与所有参考文本的相似度平均

  • 适用案例：图像描述生成（如一张 “猫追老鼠” 的图，参考文本可是 “猫在追老鼠”“老鼠被猫追”“一只猫追逐老鼠”）

三、回归任务指标（预测连续值，评估误差大小与拟合度）

1. MAE（平均绝对误差）

  • 核心：预测值与真实值的 “绝对误差” 平均值，对异常值不敏感

  • 公式：$MAE = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$（$y_i$= 真实值，$\hat{y}_i$= 预测值，n = 样本数）

  • 细节说明：绝对误差避免正负误差抵消（如 + 2 和 - 2 的误差，绝对值均为 2），异常值（如极端大的误差）对 MAE 影响小

  • 适用案例：房价预测（个别高价豪宅的预测误差不会大幅拉低整体评估）、销量预测（偶尔的促销高峰误差可接受）

2. MSE（均方误差）/ RMSE（均方根误差）

  • 核心：MSE 是 “平方误差” 平均值，放大异常值影响；RMSE 是 MSE 开方，与真实值同量纲

  • 公式：

    • MSE：$MSE = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2$

    • RMSE：$RMSE = \sqrt{MSE}$

  • 细节说明：平方运算会放大异常值（如误差 + 10 的平方是 100，远大于误差 + 2 的平方 4），适合需要 “严惩大误差” 的场景

  • 适用案例：

    • MSE：工业质量控制（如零件尺寸预测，微小误差可接受，大误差会导致零件报废，需重点惩罚）

    • RMSE：金融收益率预测（收益率单位为 “%”，RMSE 与真实值同单位，更易解释 “平均误差是多少个百分点”）

3. R²（决定系数 / 拟合优度）

  • 核心：衡量模型 “解释数据变异” 的能力，即模型比 “简单用均值预测” 好多少

  • 公式：$R² = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}i)^2}{\sum{i=1}^n (y_i - \bar{y})^2}$（$\bar{y}$= 真实值的平均值）

  • 细节说明：

    • 分子 = 模型预测的误差总和（残差平方和）；分母 = 用 “均值” 预测的误差总和（总平方和）

    • 取值范围：-∞~1，R²=1 表示模型完全拟合（预测值 = 真实值）；R²=0 表示模型和 “均值预测” 一样差；R²<0 表示模型比 “均值预测” 还差

  • 适用案例：线性回归模型评估（如 “通过面积 / 地段预测房价”，R²=0.8 表示模型能解释 80% 的房价变异）
