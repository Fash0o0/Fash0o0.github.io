【IEEE Trans. Mob. Comput.-2024-香港中文大学】FedFMSL：Federated Learning of Foundation Models With Sparsely Activated LoRA

发表于2026-03-19|更新于2026-04-21|机器学习联邦学习
|浏览量:

一、论文基本信息

  • 标题：FedFMSL: Federated Learning of Foundation Models With Sparsely Activated LoRA

  • 论文链接：https://ieeexplore.ieee.org/document/10648634/ (DOI: 10.1109/TMC.2024.3454634)

  • 作者及单位：

    • Panlong Wu, Kangshuo Li, Ting Wang：香港中文大学（深圳）理工学院、深圳智能未来网络研究院

    • Yanjie Dong, Victor C. M. Leung：深圳北理莫斯科大学人工智能研究院、粤港澳大湾区情感智能与普适计算联合实验室

    • Fangxin Wang（通讯作者）：香港中文大学（深圳）理工学院、深圳智能未来网络研究院、广东省智能未来网络重点实验室

  • 发表时间：2024 年 9 月在线发表，2024 年 12 月正式刊出于《IEEE TRANSACTIONS ON MOBILE COMPUTING》（VOL. 23, NO. 12）

  • 代码开源地址：暂未开源

  • 核心定位：针对基础模型联邦学习领域的通信开销高、边缘设备计算压力大、客户端数据非 IID 异构三大核心痛点，提出了两阶段个性化联邦学习算法 FedFMSL，融合稀疏激活 LoRA（SAL）与基础模型混合架构（MoFM），在仅微调基础模型不到 0.3% 参数量的前提下，实现了较 SOTA 基线最高 59.19% 的性能提升，完美适配资源受限的边缘计算场景。

二、研究背景与核心问题

研究背景

  1. 基础模型（FM）凭借海量参数与大规模预训练，在 NLP、CV、多模态任务中取得了突破性效果，但其训练依赖大规模数据，而用户隐私数据多分散存储在边缘设备，无法直接集中用于模型训练。

  2. 联邦学习（FL）通过 “数据不动模型动” 的协同训练范式，在不泄露客户端原始数据的前提下实现分布式模型训练，为基础模型利用边缘分散数据提供了可行路径。

  3. 现有基础模型与联邦学习的融合工作，大多仅聚焦于 prompt tuning、单一 adapter 插入等轻量化微调方案，未能同时解决通信、计算、数据异构三大核心挑战，在非 IID 场景下性能衰减严重。

核心问题

  1. 通信带宽挑战：基础模型参数量庞大，传统联邦学习的全参数传输与聚合模式，会产生极高的通信开销，远超现代移动网络的承载能力，训练效率极低。

  2. 边缘计算挑战：基础模型的训练与推理对算力要求极高，而边缘终端设备普遍存在算力、存储资源受限的问题，无法支撑全参数微调甚至全层 LoRA 微调的计算负载。

  3. 数据异构挑战：联邦学习中客户端数据天然呈非 IID 分布，会导致参数发散、分布偏差等统计问题；而基础模型的超大参数空间进一步放大了优化难度，最终造成模型性能的严重下降。

三、核心贡献

  1. 提出了两阶段个性化联邦学习框架 FedFMSL 设计了全局专家协同训练 + 本地专家个性化学习的两阶段流程，既通过联邦协同学习提取全局通用特征，又通过本地训练适配客户端个性化数据分布，同时完成了两阶段算法的收敛性理论证明，为算法有效性提供了严谨的理论支撑。

  2. 设计了稀疏激活 LoRA（SAL）轻量化微调算法 针对边缘设备资源受限的问题，提出渐进式稀疏激活机制，通过能力队列与精度阈值控制器，动态调整 LoRA 矩阵的激活层数与参数量，在保证模型性能的同时，大幅降低计算与通信开销，实现了对边缘异构设备的自适应适配。

  3. 首次构建了联邦学习场景下的基础模型混合架构（MoFM） 创新性地将全局专家与本地专家组成双专家混合模型，通过带轻量化门控适配器的门控网络，智能分配双专家的决策权重，从根本上解决了非 IID 数据带来的个性化与泛化性平衡难题，是首个在个性化联邦学习中实现多基础模型混合协同的工作。

  4. 完成了全面的实验验证与性能突破 通过多数据集、多异构程度、多主干模型的大量对比实验，验证了 FedFMSL 的通用性与优越性：仅微调不到 0.3% 的基础模型参数，在默认设置下较其他 SOTA 基线性能最高提升 59.19%，同时节省 99.95% 的通信带宽，实现了参数效率与模型性能的双重突破。

四、核心方法

整体架构：FedFMSL 两阶段训练范式

FedFMSL 面向典型的横向联邦学习场景（N 个客户端，本地私有非 IID 数据集），整体分为全局专家训练与个性化本地专家训练两个阶段，核心流程如下图所示：

  1. 第一阶段：全局专家协同训练

    1. 操作：为每个客户端的基础模型（如 CLIP）的每一个 Transformer 块插入 LoRA 低秩分解矩阵，冻结预训练主干权重，仅更新 LoRA 参数；每轮通信中，客户端仅上传 LoRA 参数至服务器，完成加权聚合后下发更新。

    2. 核心目标：激活所有插入的 LoRA 矩阵，充分学习跨客户端的全局通用特征，训练完成的模型作为第二阶段的全局专家，全程冻结权重。

    3. 优化目标： $$min {w{i}} \mathcal{F}=\frac{1}{N} \sum_{i=1}^{N} \mathbb{E}{\left(x{i}, y_{i}\right) \sim d_{i}} \mathcal{F}{i}\left(x{i}, y_{i} ; w_{i}\right$$ 其中，$$w_$$为客户端 i 的 LoRA 参数，$$\mathcal{F}$$为客户端 i 的损失函数，$$d$$为客户端 i 的数据分布。

  2. 第二阶段：个性化本地专家训练

    1. 操作：为每个客户端构建基础模型混合架构（MoFM），包含第一阶段训练的全局专家、同架构的本地专家（全局专家权重初始化）、带门控适配器的门控网络。全局专家权重全程冻结，本地专家仅在客户端本地用 SAL 算法训练，不参与全局聚合；仅门控适配器的激活参数参与每轮通信的聚合与下发。

    2. 核心目标：平衡全局泛化能力与本地个性化适配能力，解决非 IID 数据带来的性能衰减问题，同时通过稀疏激活与门控适配器设计，进一步降低计算与通信开销。

    3. 优化目标： $$min {e{i}, u_{i}} \mathcal{L}=\frac{1}{N} \sum_{i=1}^{N} \mathbb{E}{\left(x{i}, y_{i}\right) \sim d_{i}} \mathcal{L}{i}\left(x{i}, y_{i} ; e_{i}, u_{i}\right$$ 其中，$$e_$$为客户端 i 的本地专家 LoRA 参数，$$u_$$为客户端 i 的门控适配器参数。

核心模块 1：稀疏激活 LoRA（SAL）算法

  1. 基础原理 在基础模型的视觉编码器、文本编码器的每一层权重矩阵$$W_0 \in R^{E×F$$中，插入可训练的低秩分解矩阵$$\Delta W = W_A W_$$，其中$$W_A \in R^{E×H$$、$$W_B \in R^{H×F$$，且秩$$H << min(E,F$$。冻结主干权重$$W_$$，仅优化$$W_$$与$$W_$$，前向传播计算为： $$y=(W_{0}+W_{A}W_{B})$$ 该设计大幅压缩了可训练参数量，从根源上降低了计算与通信开销。

  2. 渐进式稀疏激活机制 基于 “深层网络低层提取通用特征、高层提取个性化 / 任务特征” 的先验知识，设计了从高层到低层的渐进式激活策略，核心通过能力队列 + 精度阈值控制器实现：

    1. 设计最大长度为 Q 的能力队列（Capability Queue），每轮通信后将客户端的图像分类准确率存入队列，队列满后自动弹出最早的历史数据。

    2. 设定精度阈值$$\delt$$，计算客户端 j 在第 i 轮通信的精度增量： $$\Delta_{i, j}=A c c_{i, j}-\frac{1}{Q} \sum_{t=i-Q}^{i-1} A c c_{t, j$$

    3. 若$$\Delta_{i,j} < \delt$$，判定模型训练进入瓶颈，自动激活下一层的 LoRA 矩阵，增加可训练参数量以突破性能瓶颈。

  3. 核心优势 遵循课程学习的思路，逐步提升模型优化难度，提升训练稳定性；同时可根据客户端算力、数据集难度自适应调整激活的参数量，完美适配资源受限的边缘异构设备，避免了固定参数量配置的资源浪费或性能不足问题。

核心模块 2：基础模型混合架构（MoFM）

  1. 双专家核心架构 为每个客户端构建 “全局专家 + 本地专家” 的双专家混合模型，其中：

    1. 全局专家：第一阶段训练完成的基础模型，权重全程冻结，负责提取通用特征，保证模型的跨客户端泛化能力；

    2. 本地专家：与全局专家同架构，由全局专家权重初始化，仅在客户端本地通过 SAL 算法训练，不参与全局聚合，负责提取客户端本地个性化特征，适配非 IID 数据分布。

  2. 门控权重分配机制 设计门控网络输出 0-1 之间的混合权重，智能平衡双专家的决策贡献。设全局专家提取的图像 / 文本特征为$$V_g、T_$$，本地专家提取的特征为$$V_i、T_$$，最终模型输出的余弦相似度为： $$\overline{O}{i}=\lambda{i}+\left(1-\lambda_{i}\right) 其中$$\lambda_i \in (0,1$$为门控网络输出的混合权重，$$\lambda_$$越大，模型越依赖全局通用知识，反之越依赖本地个性化知识。

  3. 轻量化门控适配器设计 为进一步降低通信开销，设计了极简的门控适配器插入门控网络，核心结构为：MLP→批归一化层→MLP→批归一化层→Softmax，最终输出 0-1 的混合权重。

    1. 训练策略：第二阶段仅优化本地专家与门控适配器，冻结门控网络主干与全局专家；

    2. 聚合策略：每轮通信中，仅客户端的门控适配器激活参数上传至服务器，按客户端数据集大小加权聚合： $$u_{global }=\frac{\left|\mathcal{D}{i}\right|}{\sum{i=0}^{N}\left|\mathcal{D}{i}\right|} \sum{i=1}^{N} u_{i$$ 聚合后的全局门控适配器参数下发至所有客户端，实现全局数据分布的学习。

    3. 效果：仅微调门控适配器，准确率仅比全门控参数微调低 0.05%，但通信资源消耗降低 97.69%，实现了极致的参数效率。

收敛性分析

论文分两个阶段完成了算法的收敛性理论证明，均采用联邦学习领域通用的标准假设：

  1. 第一阶段收敛性证明 基于损失函数 L - 平滑、梯度平方期望有界的标准假设，通过梯度下降迭代推导，证明了当学习率$$\gamma=\frac{\sqrt{\frac{1}{T}}}{\Omega$$（Ω 为常数）时，算法的收敛速率为$$O(\frac{1}{\sqrt{T}}$$，与经典联邦优化算法的收敛速率保持一致。

  2. 第二阶段收敛性证明 引入损失函数关于本地专家参数、门控适配器参数的 Lipschitz 连续性假设，以及双变量梯度有界性假设，通过平滑性不等式与迭代推导，给出了算法的收敛上界，证明了双变量联合优化下的算法收敛性，为第二阶段个性化训练的理论有效性提供了支撑。

五、实验验证

实验设置

  1. 数据集：选用 CLIP 模型经典的 3 个图像分类数据集，覆盖不同任务难度：

    1. Food101：101 类食物分类任务；

    2. EuroSAT：10 类遥感地物分类任务；

    3. UCF101：101 类视频帧人类动作分类任务。

  2. 基线模型：

    1. 主流对比基线：Vanilla Fine-Tuning (FT)、PromptFL、LayerFreeze Fine-Tuning (LFFT)；

    2. 消融实验基线：LoRA+FL、Adapter+FL、无 MoFM 架构的单流模型、全门控参数微调模型。

  3. 默认配置：主干模型为 CLIP ViT-B/16，batch size=512，学习率 = 2e-4，客户端数量 = 10，LoRA 秩 r=1，dropout=0.1，两阶段各 25 轮通信；非 IID 数据划分遵循 Dirichlet 分布，通过 α 参数控制异构程度（α 越小，异构性越强）。

核心实验结果

  1. 综合性能对比 FedFMSL 在所有异构程度、客户端数量、主干模型下，均取得了最高的分类准确率：

    1. 非 IID 场景下，α=1 时，较其他 SOTA 基线，在 Food101 最高提升 9.45%，UCF101 最高提升 22.18%，EuroSAT 最高提升 59.19%；

    2. 平均准确率较 FT、PromptFL、LFFT 分别提升 20.40%、29.90%、11.11%；

    3. 通用性验证：在 ALBEF 多模态基础模型上，较其他基线准确率增益最高达 38.85%，证明了算法对不同 Transformer 架构基础模型的适配性。

  2. 资源消耗对比

    1. 参数量效率：仅微调不到 0.3% 的基础模型参数，第一阶段仅 0.1%（153K），第二阶段仅 0.134%（417K）；而 FT 微调 100% 参数，LFFT 微调 65.78% 参数；PromptFL 虽仅微调 0.0054% 参数，但伴随严重的性能下降。

    2. 通信效率：0.1MB/s 低带宽下，FedFMSL 单轮通信仅需 8.34 秒，较 FT 算法节省 99.95% 的通信时间；真实移动网络轨迹下，单轮通信仅 0.31 秒，远低于 FT 的 210 秒、LFFT 的 138 秒。

  3. 消融实验结果

    1. MoFM 架构有效性：带 MoFM 的 ViT-B/16 模型，参数量比无 MoFM 的 ViT-L/14 模型少 27.33%，但平均准确率仍提升 1.98%，证明双专家架构能以更低的参数量实现更优的性能。

    2. SAL 算法有效性：较纯 LoRA+FL、Adapter+FL 基线，在三个数据集上准确率增益最高分别达 6.97%、14.55%、9.48%，且能根据数据集难度自适应调整激活的 LoRA 层数。

    3. 门控适配器有效性：仅微调门控适配器，准确率仅比全门控参数微调低 0.05%，但通信资源节省 97.69%，验证了轻量化设计的合理性。

  4. 超参数鲁棒性分析 论文还分析了学习率、精度阈值 δ、LoRA 秩、dropout、权重衰减等超参数对模型性能的影响，验证了算法在宽超参数区间内的鲁棒性，并给出了不同场景下的最优配置建议。

六、结论与未来工作

核心结论

  1. 提出的两阶段 FedFMSL 算法，系统性解决了基础模型联邦学习中的通信密集、计算密集、客户端数据异构三大核心挑战，实现了参数效率与模型性能的双重突破。

  2. 第一阶段通过全激活 LoRA 协同训练全局专家，仅传输 LoRA 参数，相比全参数传输节省 99.9% 以上的通信带宽；第二阶段的 MoFM 双专家架构，通过门控适配器实现了全局泛化性与本地个性化的精准平衡，仅聚合门控适配器参数即可达到 SOTA 性能。

  3. 设计的 SAL 算法，通过渐进式稀疏激活 LoRA 矩阵，完美适配边缘设备的算力约束，仅微调不到 0.3% 的基础模型参数，性能较 SOTA 基线最高提升 59.19%。

  4. 大量实验验证了算法在不同数据集、异构程度、客户端数量、基础模型主干下的有效性、通用性与鲁棒性，具备极强的边缘场景落地潜力。

未来工作

  1. 引入模型量化技术，进一步降低参数规模与计算通信开销，探索自适应量化策略，根据数据特征与模型需求动态调整量化等级。

  2. 在更广泛的数据集、更大规模的客户端集群上开展实验，进一步验证算法的扩展性与有效性。

  3. 探索算法在大语言模型（LLM）、多模态生成模型等更多类型基础模型上的适配性，拓展联邦学习 + 基础模型的应用场景。

七、关键亮点与思考

核心亮点

  1. 系统性解决三大核心痛点：区别于现有工作仅聚焦单一问题的优化，FedFMSL 通过两阶段架构 + SAL 算法解决通信与计算开销问题，通过 MoFM 双专家架构解决数据异构问题，是基础模型联邦学习领域少有的全链路优化方案。

  2. 极致的参数效率与性能平衡：打破了 “低参微调必然伴随性能损失” 的固有认知，在仅微调不到 0.3% 参数量的前提下，实现了远超全参数微调、Prompt Tuning 等方案的性能，为边缘设备的大模型联邦微调提供了可行的落地方案。

  3. 理论与实验双轮驱动：不仅完成了两阶段算法的收敛性理论证明，还通过超百组对比实验、消融实验，全面验证了各模块的有效性，结论严谨扎实，可复现性强。

  4. 强通用性与可扩展性：算法核心设计不依赖特定基础模型架构，可迁移至所有 Transformer 架构的大模型，适配 CV、NLP、多模态等多种任务场景。

研究启发与思考

  1. 个性化联邦学习的新范式：MoFM 双专家架构为大模型个性化联邦学习提供了全新思路，区别于传统 “全局模型 + 本地后微调” 的单流模式，双专家并行 + 门控动态权重的设计，能更好地适配非 IID 数据分布，为后续相关研究提供了重要参考。

  2. 边缘大模型训练的轻量化新思路：SAL 算法的渐进式激活机制，为资源受限设备的大模型训练提供了 “按需分配” 的优化思路，替代了固定参数量的静态配置，可进一步拓展至大模型的边缘推理、增量微调等场景。

  3. 落地价值与优化空间：算法在极低的资源开销下实现了 SOTA 性能，在移动端、物联网、智慧医疗等隐私敏感的边缘场景中具备极高的工程落地价值；后续可进一步融合差分隐私、同态加密等隐私增强技术，在保证性能的同时进一步提升数据隐私安全。
