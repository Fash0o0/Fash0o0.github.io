【AAAI-2026-佛罗里达大学】FedALT：Federated Fine-Tuning through Adaptive Local Training with Rest-of-World LoRA

发表于2026-03-06|更新于2026-04-21|机器学习联邦学习
|浏览量:

一、论文基本信息

  • 标题：FedALT: Federated Fine-Tuning through Adaptive Local Training with Rest-of-World LoRA

  • 作者及单位：Jieming Bian、Lei Wang、Jie Xu（佛罗里达大学）；Letian Zhang（中田纳西州立大学）

  • 发表时间：2026-03-14（AAAI Conference on Artificial Intelligence）

  • 代码开源地址：暂未开源

  • 核心定位：针对联邦大模型微调场景下，基于 FedAvg 的联邦 LoRA 方法存在的跨客户端有害干扰、全局与本地信息平衡能力不足的核心痛点，提出完全脱离 FedAvg 范式的 FedALT 个性化联邦 LoRA 微调框架，在异构任务场景下实现了更优的本地适配效果，同时不牺牲计算与通信效率。

二、研究背景与核心问题

研究背景

  1. 大语言模型 (LLM) 适配下游任务需微调，但全参数微调计算成本极高，以 LoRA 为代表的参数高效微调 (PEFT) 方法，通过低秩矩阵分解大幅压缩可训练参数量，成为大模型适配的主流方案。

  2. 大模型微调所需的高质量数据常分散在多个机构，隐私法规与安全协议禁止原始数据直接共享，联邦学习 (FL) 支持无原始数据暴露的协同微调，成为隐私保护大模型适配的核心范式。

  3. 现有联邦 LoRA 微调方法大多基于 FedAvg 框架，依赖 “本地训练 - 全局聚合 - 用聚合模型初始化下一轮本地训练” 的流程，在客户端数据 / 任务异构的真实场景中，极易出现性能退化。

  4. 现有个性化联邦 LoRA 研究大多仅解决标签异构问题，对更贴近现实的任务异构场景（不同客户端对应完全不同的 NLP 任务）的探索存在显著缺口。

核心问题

论文系统揭示了基于 FedAvg 范式的现有方法的两大核心局限：

  1. 严重的跨客户端有害干扰：全局聚合操作会抵消客户端本地微调获得的个性化提升，在部分任务上，基于 FedAvg 的方法性能甚至不如纯本地无协作微调。

  2. 全局 - 本地信息平衡能力缺失：现有方法大多依赖固定或预定义的权重因子融合全局与本地信息，无法为不同输入、不同客户端动态适配最优权重，对全局模型代表性差的客户端极不友好。

三、核心贡献

  1. 关键问题洞察：明确指出异构任务场景下的个性化联邦大模型微调研究存在显著缺口，系统论证了 FedAvg 范式在该场景下的根本性缺陷，为后续研究提供了核心问题导向。

  2. 范式级方法创新：提出了完全脱离 FedAvg 框架的 FedALT 个性化联邦微调体系，核心设计包括两点：一是解耦的双 LoRA 结构（个性化 Individual LoRA + 冻结的 Rest-of-World (RoW) LoRA），从根源上避免聚合对本地适配的干扰；二是基于混合专家 (MoE) 思想的自适应混合器，为每个输入样本动态学习双 LoRA 的最优权重，实现细粒度的全局 - 本地信息平衡。

  3. 全面的实验验证：基于 Flan 基准，在 Bloom-560M 和 Llama2-7B 两个主流大模型上开展了系统性实验，证明 FedALT 显著超越现有 SOTA 个性化联邦 LoRA 方法，在不同异构程度、客户端数量、LoRA 秩、本地训练轮次下均具备强鲁棒性，同时保持了与基线方法相当的计算与通信效率。

四、核心方法

前置基础定义

  1. LoRA 核心原理
    对于预训练权重$W_0 \in \mathbb{R}^{l×d}$，LoRA 将权重更新量$\Delta W$分解为两个低秩矩阵$A \in \mathbb{R}^{r×d}$和$B \in \mathbb{R}^{l×r}$（$r \ll min(d,l)$），最终微调后的权重为$W = W_0 + BA$。训练过程中仅更新 A、B 矩阵，可将可训练参数量从$d×l$压缩至$r×(d+l)$。

  2. 异构联邦微调问题定义
    存在$K$个客户端，每个客户端拥有独立的本地数据集$D_k = {X_k,Y_k}$，对应专属的下游任务；每个客户端的目标是利用联邦学习提取跨客户端共享知识，同时微调适配自身任务的个性化模型，整体优化目标为：
    $\min_W \frac{1}{K}\sum_{k=1}^K L_k(X_k,Y_k,W_k)$
    其中$L_k(\cdot)$为客户端$k$的损失函数，$W_k$为客户端$k$的个性化模型参数。

核心模块 1：Individual LoRA 与 RoW LoRA 双解耦设计

FedALT 为每个客户端设置两套完全解耦的 LoRA 模块，彻底打破 FedAvg 的聚合 - 初始化循环，核心设计如下：

  1. Individual LoRA（个性化本地 LoRA）

    • 记为$A_k^L / B_k^L$，由每个客户端独立维护，仅在客户端本地微调中更新，专门捕捉客户端本地的任务专属特征与知识。

    • 该模块全程隔离其他客户端的信息干扰，每轮训练均基于上一轮自身更新后的参数继续训练，而非用全局聚合模型重置初始化。

  2. Rest-of-World LoRA（RoW LoRA，全局共享 LoRA）

    • 记为$A_k^R / B_k^R$，代表除当前客户端$k$外，其他所有客户端 Individual LoRA 的平均值，计算公式为：
      $A_k^R=\frac{1}{K-1}\sum_{m \neq k}A_m^L, \quad B_k^R=\frac{1}{K-1}\sum_{m \neq k}B_m^L$

    • 核心约束：RoW LoRA 在客户端本地微调过程中全程冻结，仅在每轮通信结束后通过服务端聚合更新，彻底避免了聚合操作对客户端本地个性化适配的干扰。

    • 额外优势：RoW LoRA 不参与本地训练，将客户端的微调计算工作量降低了一半，同时避免了本地更新后再聚合导致的效果抵消问题。

核心模块 2：基于 MoE 的动态加权混合机制

为解决固定权重融合全局 - 本地信息的灵活性缺陷，论文引入基于混合专家 (MoE) 思想的自适应混合器，实现输入级的动态权重学习。

  1. 设计动机：若直接将 RoW LoRA 叠加到预训练模型中，一是存在劣质全局知识污染预训练模型的风险，二是固定权重无法为不同输入样本适配最优的全局 - 本地融合比例，缺乏细粒度调整能力。

  2. 前向传播核心公式：模型最终输出由预训练模型、Individual LoRA、RoW LoRA 三部分共同组成，融合权重由输入样本动态决定：
    $y = W_0x + \alpha_k(x)B_k^L A_k^L x + (1-\alpha_k(x))B_k^R A_k^R x$
    其中$\alpha_k(x)$为 Individual LoRA 的贡献权重，$1-\alpha_k(x)$为 RoW LoRA 的贡献权重，二者均为输入$x$的函数。

  3. 自适应混合器实现：为每个客户端设置专属的可训练混合器$G_k \in \mathbb{R}^{2×d}$（全连接层），配合 softmax 函数完成权重学习：
    $\alpha(x), 1-\alpha(x) = softmax(G_k x)$

  4. 关键约束：混合器$G_k$是客户端个性化参数，仅在本地训练中更新，不参与服务端的任何聚合操作，也不上传至服务端，确保权重调整完全适配每个客户端的独特数据分布与任务目标。

FedALT 完整算法流程

算法整体分为初始化、客户端本地训练、服务端聚合三个核心阶段，完整执行逻辑如下：

  1. 初始化阶段

    • 每个客户端随机初始化 Individual LoRA ($A_k^L/B_k^L$) 和混合器$G_k$，RoW LoRA ($A_k^R/B_k^R$) 初始化为 0。

  2. 每轮通信的客户端本地训练流程

    • 接收服务端下发的最新 RoW LoRA，替换本地旧的 RoW LoRA 模块。

    • 基于本地数据集开展多轮 epoch 微调，训练过程中仅更新 Individual LoRA 和混合器$G_k$，预训练模型$W_0$和 RoW LoRA 全程冻结。

    • 前向传播时，通过混合器动态计算双 LoRA 的融合权重，合并输出并计算损失，通过梯度下降完成参数更新。

    • 本地训练完成后，仅将更新后的 Individual LoRA 上传至服务端，混合器$G_k$保留在本地，不上传、不聚合。

  3. 每轮通信的服务端聚合流程

    • 接收所有客户端上传的 Individual LoRA 模块。

    • 为每个客户端$k$单独计算对应的 RoW LoRA，即聚合除$k$之外所有客户端 Individual LoRA 的平均值。

    • 将计算完成的 RoW LoRA 分别下发给对应的客户端，进入下一轮通信循环。

收敛性分析

论文在三大标准假设下，完成了 FedALT 的收敛性理论证明：

  1. 基础假设：损失函数满足 μ- 平滑性、λ- 强凸性，客户端最优参数对 RoW LoRA 的变化满足有界利普希茨连续性（利普希茨常数为 β）。

  2. 单轮本地收敛性：在固定 RoW LoRA 的前提下，通过梯度下降优化，客户端的可训练参数能收敛到该轮最优解的邻域内，邻域范围可通过增加本地训练步数无限缩小。

  3. 跨轮全局收敛性：当 β&lt;1 时，客户端的参数序列会收敛到一个稳定点，收敛精度由本地训练的精度决定，可通过增加本地训练轮次实现任意精度的收敛。

五、实验验证

实验基础设置

  1. 数据集：基于 Flan 基准构建，分为高异构（8 客户端各对应 1 个独立 NLP 任务）、中异构（8 客户端跨 6 个任务）、低异构（8 客户端仅 2 个任务）三种场景，每个客户端分配 600 条训练样本、300 条测试样本。

  2. 预训练模型：Llama2-7B、Bloom-560M。

  3. 对比基线：基础联邦 LoRA 方法（FedIT、FFA-LoRA）、SOTA 个性化联邦 LoRA 方法（FedDPA、PF2LoRA、FedSA、FDLoRA）、纯本地微调 Local Only。

  4. 评价指标：统一使用 ROUGE-1，实现所有生成式 NLP 任务的统一可比评估。

  5. 训练配置：本地 epoch=5，全局通信轮次 = 20，LoRA 秩 r=8，优化器 AdamW，LoRA 插入自注意力层的 q、v 组件。

核心实验结论

  1. 主性能对比：在 Llama2-7B 高异构场景下，FedALT 平均 ROUGE-1 得分 67.55，超出最优基线 FDLoRA 2.38，在自然语言推理、阅读理解等多数任务上均领先；在 Bloom-560M 上同样全面超越所有基线，平均得分 48.09，超出最优基线 2.55。

  2. 消融实验验证：① 冻结 RoW LoRA 的解耦训练设计，相比同时训练双 LoRA 的变体，即使参数量更低，仍实现了显著性能提升；② 排除客户端自身信息的 RoW LoRA，相比全局平均 LoRA 带来显著性能增益；③ 个性化动态混合器，显著优于固定权重、全局共享混合器的方案。

  3. 鲁棒性验证：FedALT 在客户端数量从 8 增加到 24、LoRA 秩从 4 到 8、本地 epoch 从 5 到 10 的不同配置下，均稳定保持对所有基线的性能优势。

  4. 异构场景适配：在高、中、低三种异构程度的场景中，FedALT 均全面超越基线，证明其对不同数据 / 任务异构程度的强适配能力。

  5. 效率验证：FedALT 的可训练参数量仅 0.0661%，与基线 FedIT（0.0622%）相当，单轮本地训练时间 7.05s、推理时间 8.94s，与基线几乎无差异，实现了性能提升不牺牲效率。

六、结论与未来工作

核心结论

  1. 提出了完全脱离 FedAvg 范式的 FedALT 个性化联邦 LoRA 微调框架，通过 Individual LoRA 与冻结 RoW LoRA 的解耦设计，从根源上解决了异构场景下的跨客户端有害干扰问题。

  2. 基于 MoE 的自适应混合器实现了输入级的全局 - 本地信息动态平衡，相比固定权重方案，实现了更细粒度的个性化适配。

  3. 大量实验证明，FedALT 在不同模型、不同异构场景、不同训练配置下，均显著超越现有 SOTA 个性化联邦 LoRA 方法，同时保持了极高的计算与通信效率，具备强工业落地潜力。

未来工作方向

  1. 探索基于聚类的多 RoW LoRA 组件方案，在保持可扩展性的同时，捕捉更细粒度的客户端间关联，进一步提升个性化能力。

  2. 将 FedALT 框架扩展到多模态基础模型的联邦微调场景中，验证其跨模态的适配能力。

  3. 构建更完善的理论框架，在更宽松的假设下完成 FedALT 的收敛性分析，提供更强的理论保证。

七、关键亮点与思考

  1. 范式级创新：彻底跳出了 FedAvg “聚合 - 初始化本地训练” 的经典框架，摒弃了用全局模型重置本地训练的模式，转而让客户端持续迭代自身的个性化 LoRA，仅通过冻结的 RoW LoRA 引入共享知识，从根源上解决了聚合带来的干扰问题，是联邦大模型微调领域的重要范式突破。

  2. 设计精巧且实用：双 LoRA 的解耦设计同时兼顾了跨客户端知识共享与本地个性化保护，冻结 RoW LoRA 的设计同时实现了抗干扰、降计算开销两大优势；无需额外的超参数调优（如 FedDPA 需调整全局 / 本地训练的阶段比例），部署门槛远低于同类个性化方法。

  3. 场景适配性强：专门针对真实工业场景中更普遍的任务异构问题设计，在低、中、高不同异构程度下均有稳定的性能提升，同时适配不同参数量级的大模型，具备极强的场景泛化能力。

  4. 可拓展空间充足：论文提出的单 RoW LoRA 设计可进一步拓展，如聚类分群的多 RoW LoRA、跨模态适配的 RoW 模块设计等，为后续个性化联邦大模型微调研究提供了全新的思路。

  5. 方法局限性：该方法专为 LoRA 等参数高效微调场景设计，若直接迁移到全参数联邦学习场景，会带来双倍的前向计算开销，实用性受限；同时单 RoW LoRA 对客户端间的细粒度差异捕捉能力仍有提升空间。
