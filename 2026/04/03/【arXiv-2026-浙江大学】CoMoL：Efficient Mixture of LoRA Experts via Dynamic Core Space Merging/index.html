【arXiv-2026-浙江大学】CoMoL：Efficient Mixture of LoRA Experts via Dynamic Core Space Merging

发表于2026-04-03|更新于2026-04-21|机器学习人工智能
|浏览量:

一、论文基本信息

  • 标题：CoMoL: Efficient Mixture of LoRA Experts via Dynamic Core Space Merging

  • 作者及单位：Jie Cao\、Zhenxuan Fan\、Zhuonan Wang、Tianwei Lin、Wenqiao Zhang†、Feifei Shao、Hongwei Wang、Jun Xiao、Siliang Tang（浙江大学）；Ziyuan Zhao、Rolan Yan（腾讯）（* 为共同一作，†为通讯作者）

  • 发表时间：2026 年 2 月（arXiv 预印本，[cs.CL](cs.CL) 方向）

  • 代码开源地址：暂未开源

  • 核心定位：针对现有 MoE-LoRA 架构存在的参数效率受限、适配粒度粗糙的核心痛点，提出 CoMoL 新型 MoE-LoRA 框架，通过核心空间专家与核心空间路由两大核心组件，在与标准 LoRA 持平的参数与计算开销下，实现细粒度 token 级适配，在数学推理、代码生成等多任务上全面超越现有 SOTA 方法。

二、研究背景与核心问题

研究背景

大语言模型全量微调成本极高、易出现灾难性遗忘，以 LoRA 为代表的参数高效微调（PEFT）方法，通过低秩分解仅更新少量参数即可实现模型适配，成为主流方案。但单 LoRA 模块盲目提升秩无法带来性能的线性增长，因此学界将 MoE 与 LoRA 结合，提出 MoE-LoRA 范式，通过多 LoRA 专家 + 动态路由提升模型表达能力。

核心问题

现有 MoE-LoRA 方法始终无法解决效率与表达能力的两难困境，存在两大核心瓶颈：

  1. 参数效率严重受限：传统 MoE-LoRA 为每个专家复制完整的 LoRA 矩阵对，参数量随专家数量 N 呈 N 倍增长，严重违背 PEFT 的核心设计初衷，且存在大量参数冗余；同时路由网络参数量随模型维度线性增长，带来额外的存储与计算瓶颈。

  2. 适配粒度过于粗糙：软合并类 MoE-LoRA 方法（如 SMEAR）采用实例级路由，基于整个样本的平均表征做专家合并，样本内所有 token 共用同一套专家权重，丢失了 token 级的细粒度动态适配能力；而 token 级路由的软 / 稀疏 MoE-LoRA，分别面临 N 倍 FLOPs 增长、推理延迟显著提升的问题，无法兼顾效率与细粒度适配。

三、核心贡献

  1. 问题层面：厘清 MoE-LoRA 的核心瓶颈

系统揭示了现有 MoE-LoRA 方法性能与效率失衡的根源 ——LoRA 专家数量膨胀带来的参数冗余，以及实例级路由导致的细粒度适配能力缺失，并明确了理想 MoE-LoRA 架构的三大设计目标：保留专家特性的同时最小化参数量、降低激活专家的计算开销、维持 token 级路由且控制路由延迟。

  1. 方法层面：提出 CoMoL 全新 MoE-LoRA 框架

创新性地提出 LoRA 核心空间的数学表征形式，设计了核心空间专家与核心空间路由两大核心组件：前者将专家差异化信息约束在与 LoRA 秩匹配的紧凑核心矩阵中，从根源上解决专家参数冗余问题；后者将路由网络投影至 LoRA 的低秩空间，在不损失表达能力的前提下极致压缩路由开销。同时，CoMoL 首次实现了 token 级的 LoRA 专家参数软合并，打破了 “效率 - 细粒度适配” 的两难困境，在与标准 LoRA 相当的参数与计算成本下，完整保留了多专家的表达能力。

  1. 实验层面：全面验证方法的优越性与可扩展性

通过数学推理、代码生成两大核心任务的系统性实验，验证了 CoMoL 在不同模型架构（Qwen3-8B/14B、Llama3.1-8B）、不同 LoRA 秩、不同专家数量下的稳定优势：在参数量与标准 LoRA 持平的前提下，持续超越各类 MoE-LoRA SOTA 方法；同时具备极强的可扩展性，专家数量扩展至 64 仍无显存溢出问题，而同类方法在 16 专家时即出现 OOM，充分证明了其工程实用价值。

四、核心方法

4.1 基础理论铺垫

LoRA 基础原理

对于冻结的预训练权重矩阵 $W \in \mathbb{R}^{m ×n}$，LoRA 通过低秩分解拟合权重更新量 $\Delta W$，即：

$W+\Delta W=W+B A$

其中 $B \in \mathbb{R}^{m ×r}$、$A \in \mathbb{R}^{r ×n}$ 为可训练参数，秩 $r \ll min(m, n)$，前向计算为：

$h=W x+B A x$

传统 MoE-LoRA 的固有局限

传统 MoE-LoRA 包含 N 个独立的 LoRA 专家 ${E_1,E_2,…,E_N}$，每个专家对应一组独立的 ${B_i,A_i}$，前向计算为：

$h=W x+\sum_{i \in \mathcal{T}(x)} G(x){i} \cdot B{i} A_{i} x$

其核心局限在于：

  • 参数量复杂度为 $O(N(m+n)r)$，随专家数 N 线性增长，参数冗余严重；

  • 软路由激活所有专家，带来 N 倍 FLOPs 增长；稀疏路由降低理论 FLOPs，但引入极高的推理延迟；

  • 实例级软合并方法虽将 FLOPs 降至标准 LoRA 水平，但丢失了 token 级的细粒度适配能力。

4.2 LoRA 核心空间的数学定义

CoMoL 的核心创新源于对 LoRA 权重的 SVD 解耦，通过对 LoRA 的 B、A 矩阵做缩减 SVD 分解：

$B=U_{B} \sum {B} V{B}^{\top }, \quad A=U_{A} \sum {A}V{A}^{\top }$

其中 $U_{B} \in \mathbb{R}^{m ×r}$、$\sum {B} \in \mathbb{R}^{r ×r}$、$V{B}^{\top} \in \mathbb{R}^{r ×r}$，$U_{A} \in \mathbb{R}^{r ×r}$、$\sum {A} \in \mathbb{R}^{r ×r}$、$V{A}^{\top} \in \mathbb{R}^{r ×n}$。

定义核心矩阵 $M \in \mathbb{R}^{r ×r}$：

$M=\sum_{B} V_{B}^{\top} U_{A} \sum_{A}$

由此，LoRA 的权重更新可被紧凑解耦为：

$\Delta W=U_{B} M V_{A}^{\top }$

在该表征中，$U_B$ 和 $V_A^\top$ 构成了决定特征方向的奇异子空间，而核心矩阵 M 则负责调制潜在维度间的耦合强度与权重分配，这是 CoMoL 实现参数压缩的数学基础。

4.3 核心空间专家（Core Space Experts）

核心假设

不同 LoRA 专家共享高度相似的奇异子空间 $U_B$ 和 $V_A^\top$，专家间的差异化知识完全可由紧凑的核心矩阵 $M_i$ 表征，无需为每个专家复制完整的高维 LoRA 矩阵对。

前向计算重构

基于上述假设，CoMoL 将 N 个专家的可训练参数约束在 N 个 $r×r$ 的核心矩阵 $M_i$ 中，全局共享 $U_B$ 和 $V_A^\top$，前向计算改写为：

$h=W x+\sum_{i=1}^{N} G(x){i} \cdot\left(U{B} M_{i} V_{A}^{\top}\right) x$

两大核心优势

  1. 极致的参数效率

传统 MoE-LoRA 的专家参数量复杂度为 $O(N(m+n)r)$，而 CoMoL 将其降至 $O((m+n)r+N·r^2)$。由于常规设置下 $r \ll m,n$（如 r=8，n=4096），专家数量 N 增长时，模型整体参数量几乎保持恒定，完全贴合 PEFT 的设计原则。

  1. token 级软合并，零额外计算开销

利用矩阵乘法的分配律，前向公式可等价变换为：

$h=W x+U_{B}\left(\sum_{i=1}^{N} G(x){i} M{i}\right) V_{A}^{\top} x$

该式实现了 token 级的专家软合并：对每个输入 token，先通过路由权重将 N 个核心矩阵软合并为单个合并矩阵 $M_{merged}$，再执行高维投影计算。高维矩阵 $U_B$ 和 $V_A^\top$ 对每个 token 仅需计算一次，主计算量的 FLOPs 降至与标准 LoRA 完全一致的水平，同时完整保留了 token 级的动态适配能力。

计算复杂度对比

对于包含 L 个 token 的批次，传统 MoE-LoRA 输出级融合的 FLOPs 为：

$2 ×L ×r ×(2n+r) ×N + L ×n ×(N-1)$

而 CoMoL 核心空间合并的 FLOPs 仅为：

$2 ×L ×r ×(2n+r) + L ×r^2 ×(N-1)$

主计算开销降至传统方法的 1/N，且核心矩阵合并的额外开销因 $r^2 \ll n$ 可忽略不计。

4.4 核心空间路由（Core Space Routing）

传统 MoE-LoRA 的路由网络权重 $W_g \in \mathbb{R}^{N×n}$，参数量复杂度为 $O(N·n)$，随模型维度 n 线性增长，成为额外的性能瓶颈。CoMoL 的核心空间路由针对该问题做了极致优化：

  1. 复用 LoRA 低秩投影的中间结果 $\hat{x}=V_A^\top x \in \mathbb{R}^r$，将其作为路由网络的输入，替代原始高维 token 表征 x；

  2. 路由权重计算变为 $G(\hat{x})=softmax(W_g \hat{x})$，其中路由权重 $W_g \in \mathbb{R}^{N×r}$，参数量复杂度从 $O(N·n)$ 降至 $O(N·r)$。

在常规设置下（r=8，n=4096），该设计将路由网络的参数量与计算开销压缩了 512 倍，且完全不损失 token 级路由的细粒度动态性。

4.5 CoMoL 完整前向流程

  1. 对输入 token x，计算低秩投影 $\hat{x}=V_A^\top x$；

  2. 核心空间路由计算每个专家的 token 级权重 $G(\hat{x})_i$；

  3. 软合并核心矩阵：$M_{merged}=\sum_{i=1}^N G(\hat{x})_i M_i$；

  4. 计算最终输出：$h=Wx + U_B M_{merged} \hat{x}$。

五、实验验证

5.1 实验设置

  • 基线方法：标准 LoRA、软权重 MoE-LoRA（MoLoRA、HydraLoRA）、稀疏 MoE-LoRA（MoLA、AdaMoLE、SparseMoA）、先进 PEFT 方法（DenseLoRA、FlyLoRA）；

  • 骨干模型：Qwen3-8B、Qwen3-14B、Llama3.1-8B，LoRA 秩默认设为 8，专家数默认 8（Qwen3-8B）/4（Qwen3-14B）；

  • 核心任务：①数学推理：微调 Math14k 数据集，评测 GSM8K、AQuA 等 6 个数据集，指标为准确率；②代码生成：微调 CodeAlpaca-20k 数据集，评测 HumanEval 基准，指标为 pass@1/5/10；

  • 扩展性实验：LoRA 秩缩放、专家数量缩放实验，以及核心空间路由的消融实验。

5.2 核心实验结果

  1. 数学推理任务

Qwen3-8B 上，CoMoL 平均准确率 84.48%，超出标准 LoRA 1.7 个百分点，参数量仅 25.16M（与 LoRA 的 24.77M 基本持平），在 AQuA 数据集上超 LoRA 7.2 个百分点，同时超越了参数量 4 倍于自身的 MoLoRA、MoLA 等方法；Qwen3-14B 上，CoMoL 平均准确率 86.34%，超标准 LoRA 1.16 个百分点，在所有基线中取得最优性能，验证了跨模型规模的稳定性。

  1. 代码生成任务

Llama3.1-8B 上，CoMoL pass@1 达 35.00%，超越所有基线，参数量仅 23.24M，与标准 LoRA 持平；Qwen3-8B 上，CoMoL pass@1 达 48.11%，大幅超越第二名 DenseLoRA（46.82%），在长思维模型上展现出稳定的学习能力，避免了 FlyLoRA 等方法在不同架构上的性能崩塌。

  1. 扩展性与消融实验

秩缩放：CoMoL 在所有秩设置下均持续超越标准 LoRA，参数量始终与 LoRA 保持同一量级；

专家数缩放：CoMoL 在 8 专家时取得最优性能，可平滑扩展至 64 专家而无 OOM 问题，而 HydraLoRA 等方法在 16 专家时即出现显存溢出；

消融实验：无核心空间路由的 CoMoL 与完整模型性能相当，但参数量随专家数增长显著提升，验证了核心空间路由在不损失性能的前提下极致压缩参数量的有效性。

六、结论与未来工作

核心结论

针对现有 MoE-LoRA 架构参数效率低下、适配粒度粗糙的核心痛点，论文提出的 CoMoL 框架，通过核心空间专家与核心空间路由两大创新设计，实现了 token 级的细粒度专家软合并，同时将参数与计算开销控制在与标准 LoRA 相当的水平。大量系统性实验证明，CoMoL 在数学推理、代码生成等多任务、多骨干模型、多配置下，均持续超越现有 MoE-LoRA SOTA 方法，具备极强的有效性、可扩展性与工程实用价值，为大语言模型的参数高效微调提供了全新范式。

局限性与未来工作

  1. 局限性：当前 PEFT 领域的研究多聚焦于参数效率优化，缺乏对不同微调场景下 PEFT 方法学习容量边界的系统性探究；现有评测体系无统一的基准框架来评估不同 PEFT 方法的学习能力，导致部分方法在不同模型架构、任务上的性能波动极大。

  2. 未来工作：针对 PEFT 方法的学习容量边界开展系统性研究，构建标准化的评测基准与框架，全面厘清不同 PEFT 方法的能力边界与适用场景。

七、关键亮点与思考

关键亮点

  1. 数学层面的根源创新：基于 SVD 分解对 LoRA 权重进行解耦，首次提出核心矩阵的表征形式，从数学根源上解决了 MoE-LoRA 专家参数冗余的问题，实现了多专家表达能力与极低参数量的兼得。

  2. 架构层面的范式突破：首次实现了 token 级的 LoRA 专家参数软合并，打破了传统方法 “实例级合并保效率、token 级路由高开销” 的两难困境，在标准 LoRA 的开销下实现了细粒度的输入自适应适配。

  3. 极强的工程落地价值：路由网络的低秩投影设计进一步压缩了额外开销，模型可平滑扩展至 64 个专家无显存压力，无需复杂的稀疏算子优化，极易部署落地，完美适配大模型端侧部署、多场景适配等工业场景。

  4. 优秀的泛化性与稳定性：在不同规模、不同架构的骨干模型上均取得稳定的性能提升，无领域 / 架构偏好，适配数学推理、代码生成等不同能力维度的下游任务，普适性极强。

深度思考

  1. 方法本质：CoMoL 的核心是将 MoE 的专家差异化信息从高维权重空间压缩到低秩核心空间，本质上是对 LoRA 低秩特性的极致挖掘，证明了多专家的能力差异并非来自高维子空间的差异，而是低秩空间内的权重调制，为 PEFT 方法的设计提供了全新的底层思路。

  2. 拓展方向：该核心空间的设计范式可拓展至其他 PEFT 方法，也可与多任务 / 多领域 LoRA 合并结合，实现更高效的多专家能力融合；同时，核心矩阵的设计也为 LoRA 的可解释性分析提供了新的视角。

  3. 行业价值：在大模型轻量化、端侧部署的行业趋势下，CoMoL 在不增加显存开销的前提下显著提升模型适配能力，有望成为标准 LoRA 之后的新一代主流 PEFT 方案。
